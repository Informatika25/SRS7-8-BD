

# Веб-сервис учета заявок и инструментов 

---

## 1. Назначение
Веб-приложение предназначено для автоматизации учета обращений/заявок (тикет-система) и управления запросами на выдачу/возврат рабочего инвентаря и оборудования. Система ориентирована на сотрудников подразделений (подача заявок, отслеживание статуса) и диспетчеров/администраторов (модерация, распределение инвентаря, аудит событий).

---

## 2. Функциональность
- Регистрация и аутентификация пользователей через стандартные сессии Django.
- Дашборд пользователя с отображением сводки и истории действий.
- Учет заявок (`tickets`): создание, фильтрация, просмотр деталей и динамическое переключение статусов через REST API.
- Учет оборудования (`instruments`): каталог доступных инструментов, формирование запросов на бронирование/выдачу, фиксация событий и снимков состояний (snapshots).
- Интерактивный UI на базе фронтенд-шаблонов Tabler и асинхронных запросов (`Fetch API`) без полной перезагрузки страниц.
- Ограничения: изменение статусов доступно только аутентифицированным пользователям с проверкой прав владения/роли и валидацией CSRF-токена.


---

## 3. Технологии
- **Язык**: Python 3.10+
- **Backend**: Django 5.x, Django REST Framework (DRF)
- **Frontend**: HTML5, Django Templates, Tabler UI (CSS/JS), Vanilla JavaScript (`fetch`)
- **База данных**: SQLite (локально) / PostgreSQL (продакшн на Render)
- **Сервер / Инфраструктура**: Gunicorn, WhiteNoise, python-dotenv, dj-database-url

---

source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

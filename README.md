# Веб-приложение учета заявок

Комплексное веб-решение для регистрации инцидентов/обращений сотрудников и контроля выдачи рабочего инвентаря.

---

## 1. Назначение
Проект решает задачу централизованного учета внутренних обращений и оборудования в организации.  
Целевая аудитория:
- **Сотрудники/пользователи**: создание тикетов о неисправностях, запрос оборудования, отслеживание статуса исполнения.
- **Диспетчеры и администраторы**: обработка поступающих тикетов, распределение инвентаря, фиксация аудита событий и состояний.

---

## 2. Функциональность
- **Управление заявками (`tickets`)**:
  - Создание, редактирование и просмотр инцидентов.
  - Динамическое изменение статусов (`new`, `in_progress`, `closed`) через асинхронный REST API.
- **Управление инвентарем (`instruments`)**:
  - Каталог оборудования с инвентарными номерами и текущими статусами доступности.
  - Формирование заявок на выдачу и возврат оборудования.
  - Ведение журнала событий и аудита со снимками наименований (`snapshots`).
- **Пользовательский интерфейс**:
  - Адаптивный дашборд на компонентах Tabler UI.
  - Клиентский скрипт `app.js` для работы с API без полной перезагрузки страницы.
- **Ограничения**:
  - Все изменяющие действия требуют аутентификации и валидации CSRF-токена.
  - Права на изменение статусов контролируются на уровне серверных представлений и DRF.

---

## 3. Технологии
- **Язык**: Python 3.10+
- **Backend**: Django 5.x, Django REST Framework (DRF)
- **Frontend**: HTML5, Django Templates, Tabler UI (CSS/JS), Vanilla JavaScript (`fetch`)
- **База данных**: SQLite (по умолчанию для разработки) / PostgreSQL (для продакшн)
- **Сервер / Инфраструктура**: Gunicorn, WhiteNoise, python-dotenv, dj-database-url
